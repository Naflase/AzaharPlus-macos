AzaharPlus for macOS: a 3DS emulator for Apple Silicon Macs

Native arm64 builds of the AzaharPlus 3DS emulator for Macs with an M1, M2, M3 or M4 chip, with the public multiplayer lobby ready out of the box.

What is AzaharPlus for macOS?

AzaharPlus is a fork of Azahar, an open source Nintendo 3DS emulator. This project is an unofficial macOS fork that builds and publishes AzaharPlus for Apple Silicon Macs, based on AzaharPlus 2126.2-A with macOS build fixes.

Features

  • AzaharPlus extras: compatibility with game files that work on any Citra fork, built-in cheats, Amiibo generation, ZipPass (StreetPass data exchange through zip files) and the ability to download system files from official servers.
  • Public lobby ready: the default lobby server is preconfigured and a random network token is generated on first launch, so you can join and host public rooms without setup.
  • Native Apple Silicon: arm64 build for M1, M2, M3 and M4 Macs, no Rosetta needed.
  • Vulkan through MoltenVK: the Vulkan renderer runs on top of Metal.
  • Free and open source: GPL licensed, with the full source and build scripts on GitHub.

How to install on macOS

  1. Download AzaharPlus-macos-arm64-macos-2126.2-A.zip and unzip it.
  2. Move AzaharPlus.app to /Applications.
  3. The app is ad hoc signed and not notarized, so remove the quarantine flag in Terminal: 
    xattr -dr com.apple.quarantine /Applications/AzaharPlus.app
  4. On first launch, right-click the app and choose Open.

You need to provide your own legally dumped games. This project does not distribute games or links to them.

Multiplayer and public rooms

Public multiplayer works out of the box. Open the multiplayer menu to browse public rooms on the preconfigured lobby server or host your own room. AzaharPlus also improves multiplayer compatibility with other Citra forks.

3DS Link (using a real 3DS)

If you want to bring a real Nintendo 3DS into the setup, the third-party project 3DS-Link by gionko may be of interest. It is independent from this project; check its own page for what it supports.

Build from source

Homebrew's Qt must not be in your PATH, because the build downloads its own Qt.

brew install ccache ninja spirv-tools ffmpeg@7 sdl3
git clone https://github.com/Naflase/AzaharPlus-macos.git
cd AzaharPlus-macos
TARGET=arm64 ./.ci/macos.sh

See the README for details.

Frequently asked questions

Is this the official AzaharPlus or Azahar?

No. This is an unofficial macOS fork of AzaharPlus, which is itself a fork of Azahar. It is not affiliated with Azahar, AzaharPlus or Nintendo. The official projects are at github.com/AzaharPlus/AzaharPlus and azahar-emu.org.

Which Macs does it support?

Native arm64 builds for Apple Silicon Macs (M1, M2, M3, M4 and later). Intel Macs are not supported. The minimum macOS version is given in each release notes; the current build needs macOS 27.2 or later because the bundled FFmpeg libraries were built for that version.

Why does macOS say the app cannot be opened?

The app is ad hoc signed but not notarized by Apple. Follow the install steps above: remove the quarantine flag with xattr, then right-click the app and choose Open on first launch.

Does it come with games or console system files?

No. You need to provide your own legally dumped games. AzaharPlus can download system files from official servers, so a real 3DS is not required for that step.

How do I play online with other people?

Public multiplayer works out of the box. The default lobby server is preconfigured and a random network token is generated on first launch, so you can browse public rooms and host your own without extra setup.

Is it free, and can I build it myself?

Yes. It is free and open source (GPL). Build instructions are in the section above and in the repository.
